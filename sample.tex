\cvsection{Опыт работы}

\cvevent{Программист встраиваемых систем}{ЮВС Авиа (концерн «Калашников»)}{Сентябрь 2025 — настоящее время}{}

\begin{itemize}
  \item Разработал \textbf{ППРЧ} для связи по \textbf{UDP} через Wi-Fi на \textbf{Embedded Linux} (Raspberry Pi, RTL8812EU): переключение каналов Wi-Fi 10 раз в секунду для устойчивости к РЭБ.
  \item Реализовал \textbf{Bidirectional DSHOT} на \textbf{C} для STM32F7: чтение оборотов моторов без отдельного датчика.

  \github{RaulIQ/bit-banging-bidir-dshot}
  \item Разработал на \textbf{C} (ESP-IDF, \textbf{FreeRTOS}) двунаправленный UART-мост MAVLink для ESP32-C3/S3 с шифрованием \textbf{AES-128-CTR}: аппаратная и программная реализации, замер времени расшифровки.
  \item Написал на \textbf{Python} \textbf{HIL-тест} моста: ПК через два USB-UART прогоняет поток MAVLink через пару ESP32, сверяет кадры байт-в-байт и порядок seq, измеряет потери и задержку под нагрузкой.
\end{itemize}

  \item Разработал систему \textbf{бортовой телеметрии и диагностики} («чёрный ящик»): запись полётных данных на SPI-flash в собственном формате. Добавил async API в форк spi-memory, чтобы запись не блокировала другие задачи.
